API仕様

ベースURL: https://810ch.yajuvideo.st/api/v1

認証（いずれかのヘッダー）。キーは板slug入りの 810ch_miichan_xxxx… 形式:

Authorization: Bearer 810ch_miichan_xxxxxxxxxxxxxxxx
# または
X-API-Key: 810ch_miichan_xxxxxxxxxxxxxxxx

レートリミット: 板ごとに300リクエスト/分。 超過したリクエストには 429 Too Many Requests を返す（Retry-Afterヘッダーに再試行可能までの秒数が入る）。

エンドポイント（{slug} はこの板のスラグ miichan）:

メソッドとパス機能
GET /api/v1/boards/{slug}板情報の取得
GET /api/v1/boards/{slug}/threadsスレ一覧の取得（page, per_page）
GET /api/v1/boards/{slug}/threads/{thread_key}スレ詳細とレス一覧の取得（page, per_page）
GET /api/v1/boards/{slug}/responses板への書き込み一覧（最大50件、start_at任意、通常削除済みは除外）
GET /api/v1/boards/{slug}/threads/{thread_key}/responses/{number}単一レスの取得
DELETE /api/v1/boards/{slug}/threads/{thread_key}/responses/{number}レスの透明削除（番号繰り上げ）
POST /api/v1/boards/{slug}/threads/{thread_key}/responses/{number}/abornレスの通常削除（削除文言で上書き）
POST /api/v1/boards/{slug}/threads/{thread_key}/force_sage強制sageの有効化
DELETE /api/v1/boards/{slug}/threads/{thread_key}/force_sage強制sageの解除
POST /api/v1/boards/{slug}/threads/{thread_key}/threadstopスレストの有効化
DELETE /api/v1/boards/{slug}/threads/{thread_key}/threadstopスレストの解除
DELETE /api/v1/boards/{slug}/threads/{thread_key}スレッドの削除
GET /api/v1/boards/{slug}/post_keys認証キーの一覧（認証キーID・書込数・発行IP/UA等）
GET /api/v1/boards/{slug}/post_keys/{public_id}/writingsそのキーの書き込み履歴（通常削除済みを除く最新50件・時系列）
DELETE /api/v1/boards/{slug}/post_keys/{public_id}認証キーの無効化（そのキーでの書き込み不可に。紐付けは保持）
POST /api/v1/boards/{slug}/post_keys/{public_id}/aborn_allそのキーの全書き込みを通常削除

スレ/レスの取得系は管理用情報（IPアドレス、User-Agent、投稿元、tuid、書き込みに使われた認証キー、削除状態・理由）も返す。 認証キーの発行はセルフ発行のみで、APIからは行えない。

パラメータ:

パラメータ対象エンドポイント必須説明
reason 通常削除（aborn） ✕ 削除理由。指定するとレスの aborn_reason と削除ログに記録される。
page スレ一覧 / スレ詳細 ✕ ページ番号（デフォルト: 1）
per_page スレ一覧 / スレ詳細 ✕ 1ページの件数（デフォルト: 20、最大: 100）
start_at 書き込み一覧 ✕ 始点（unix秒）。指定時刻以降の書き込みを時系列で返す。未指定時は最新50件

curlサンプル（{thread_key} はスレURL末尾の10桁、{number} はレス番号、{public_id} は認証キーの認証キーID（pk_…。認証キー一覧で確認できる）に置き換える）:

共通（キー設定）
KEY="810ch_miichan_xxxx…"
GET 板情報の取得 
curl -H "Authorization: Bearer $KEY" https://810ch.yajuvideo.st/api/v1/boards/miichan
GET スレ一覧の取得（page, per_page） 
curl -H "Authorization: Bearer $KEY" "https://810ch.yajuvideo.st/api/v1/boards/miichan/threads?page=1&per_page=20"
GET スレ詳細とレス一覧の取得 
curl -H "Authorization: Bearer $KEY" https://810ch.yajuvideo.st/api/v1/boards/miichan/threads/{thread_key}
GET 板への書き込み一覧（start_at任意） 
curl -H "Authorization: Bearer $KEY" "https://810ch.yajuvideo.st/api/v1/boards/miichan/responses?start_at=1791000000"
GET 単一レスの取得 
curl -H "Authorization: Bearer $KEY" https://810ch.yajuvideo.st/api/v1/boards/miichan/threads/{thread_key}/responses/{number}
DELETE レスの透明削除（番号繰り上げ） 
curl -X DELETE -H "Authorization: Bearer $KEY" https://810ch.yajuvideo.st/api/v1/boards/miichan/threads/{thread_key}/responses/{number}
POST レスの通常削除（reasonは任意） 
curl -X POST -H "Authorization: Bearer $KEY" -d "reason=スパム" https://810ch.yajuvideo.st/api/v1/boards/miichan/threads/{thread_key}/responses/{number}/aborn
POST 強制sageの有効化 
curl -H "Authorization: Bearer $KEY" -X POST https://810ch.yajuvideo.st/api/v1/boards/miichan/threads/{thread_key}/force_sage
DELETE 強制sageの解除 
curl -X DELETE -H "Authorization: Bearer $KEY" https://810ch.yajuvideo.st/api/v1/boards/miichan/threads/{thread_key}/force_sage
POST スレストの有効化 
curl -H "Authorization: Bearer $KEY" -X POST https://810ch.yajuvideo.st/api/v1/boards/miichan/threads/{thread_key}/threadstop
DELETE スレストの解除 
curl -X DELETE -H "Authorization: Bearer $KEY" https://810ch.yajuvideo.st/api/v1/boards/miichan/threads/{thread_key}/threadstop
DELETE スレッドの削除 
curl -X DELETE -H "Authorization: Bearer $KEY" https://810ch.yajuvideo.st/api/v1/boards/miichan/threads/{thread_key}
GET 認証キーの一覧 
curl -H "Authorization: Bearer $KEY" https://810ch.yajuvideo.st/api/v1/boards/miichan/post_keys
GET そのキーの書き込み履歴 
curl -H "Authorization: Bearer $KEY" https://810ch.yajuvideo.st/api/v1/boards/miichan/post_keys/{public_id}/writings
DELETE 認証キーの無効化 
curl -X DELETE -H "Authorization: Bearer $KEY" https://810ch.yajuvideo.st/api/v1/boards/miichan/post_keys/{public_id}
POST そのキーの全書き込みを通常削除 
curl -H "Authorization: Bearer $KEY" -X POST https://810ch.yajuvideo.st/api/v1/boards/miichan/post_keys/{public_id}/aborn_all

APIキーはこの板（みいちゃんと山田さん掲示板）専用。
