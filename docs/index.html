GET 板情報の取得 /boards/{slug}
板の基本情報（タイトル、設定、スレ数など）を取得します。
curl -H "Authorization: Bearer $KEY" https://810ch.yajuvideo.st/api/v1/boards/{slug}
GET 板への書き込み一覧 /boards/{slug}/responses
最大50件の書き込みを取得。通常削除済みは除外されます。管理用情報（IP, UA, tuid等）も含まれます。
start_at: 始点unix秒。指定時刻以降を時系列で取得。未指定時は最新50件。
curl -H "Authorization: Bearer $KEY" "https://810ch.yajuvideo.st/api/v1/boards/{slug}/responses?start_at=1791000000"
GET スレッド一覧 /boards/{slug}/threads
スレッド一覧をページネーションで取得します。
page: ページ番号 (初期値: 1) / per_page: 1ページの件数 (初期値: 20, 最大: 100)
curl -H "Authorization: Bearer $KEY" "https://810ch.yajuvideo.st/api/v1/boards/{slug}/threads?page=1&per_page=20"
特定スレッドの取得 & 制御 /threads/{thread_key}
thread_key はスレURL末尾の10桁（識別キー）です。
スレ詳細取得: GET /api/v1/boards/{slug}/threads/{thread_key}?page=1&per_page=20
強制sage: POSTで有効化、DELETEで解除
スレスト: POSTで書き込み停止、DELETEで停止解除
スレッド削除: DELETEでスレッドを完全削除（警告あり）
単一レスの取得・削除 .../threads/{thread_key}/responses/{number}
単一レス取得: IP, UA, 認証キー等の管理用情報を含むレス情報を取得。
透明削除 (DELETE): 掲示板上で番号が繰り上がり、痕跡を残さず削除。
通常削除 / aborn (POST .../aborn): 本文を「あぼーん（削除文言）」で上書き。削除理由（reason）を記録可能。
# 通常削除 (aborn)
curl -X POST -H "Authorization: Bearer $KEY" -d "reason=スパム" https://810ch.yajuvideo.st/api/v1/boards/{slug}/threads/{thread_key}/responses/{number}/aborn

# 透明削除
curl -X DELETE -H "Authorization: Bearer $KEY" https://810ch.yajuvideo.st/api/v1/boards/{slug}/threads/{thread_key}/responses/{number}
GET 認証キー一覧 /boards/{slug}/post_keys
板で発行された認証キーの一覧（認証キーID public_id, 書込数, 発行IP/UA等）を取得します。
※認証キーの新規発行はセルフ発行のみで、APIからは行えません。
curl -H "Authorization: Bearer $KEY" https://810ch.yajuvideo.st/api/v1/boards/{slug}/post_keys
キー指定操作 (履歴 / 無効化 / 一括削除) /post_keys/{public_id}...
{public_id} は認証キー一覧で得られるID（pk_...形式）です。
書き込み履歴 (GET .../writings): 通常削除済みを除く最新50件を時系列で取得。
認証キー無効化 (DELETE .../{public_id}): 今後の書き込みを禁止（過去の紐付けは保持）。
全書き込み通常削除 (POST .../aborn_all): そのキーで行われた全書き込みを通常削除。
# 全書き込み削除
curl -H "Authorization: Bearer $KEY" -X POST https://810ch.yajuvideo.st/api/v1/boards/{slug}/post_keys/{public_id}/aborn_all
